Local inspection of Minecraft26.2's actual client bytecode found that `GlyphRenderState.textureSetup()` explicitly requests NEAREST sampling, including for the dedicated four-times-oversampled Noto TrueType glyphs. The GUI sprite atlas also uses nearest sampling, even though Votex's round/edge textures are160px for40 logical units and its icons96px. This explains why higher-resolution source assets alone did not remove the stepped appearance.

The in-progress correction sets linear sampling in each Votex glyph draw state and only inside the extraction scope of Votex glass/icon draws. The glyph carries an immutable marker from the dedicated `SmoothUiFont`; layout, native rasterization, fallback and drawing are delegated to Minecraft. It does not mutate Minecraft's shared atlas sampler or globally blur vanilla text/items/skins/world textures. Scope exit uses `finally`; the existing immutable render-state flow is preserved and uses Mojang's GPU sampler API without raw OpenGL calls. A native follow-up checks actual draw counts and visually compares the real output at multiple sizes.
