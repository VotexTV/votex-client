Capes require a complete64×32 PNG: signature/chunk sequence/CRC, legal color/bit-depth/interlace fields, a terminated compressed image stream, exact bounded scanline lengths and valid filter types. Inflation is capped by the declared pixel layout. This is a structural/scanline validator rather than a full independent pixel renderer. It uses the Workers-supported DecompressionStream API documented at https://developers.cloudflare.com/workers/runtime-apis/web-standards/#compression-streams .
