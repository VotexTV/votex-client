# First-time Simple Voice Chat provisioning

Status: the production permission gate passed the isolated native Minecraft run04. First-time provisioning now depends on the capability in the **actual enabled Core JAR**, rather than a launcher-wide readiness constant. The existing packaged Core is not silently treated as having new code. No installer or public release was produced.

Inspection of Simple Voice Chat's microphone lifecycle found that muted/disabled state alone does not prevent physical microphone initialization. The typed adapter intercepts **upstream-internal** `StartMicEvent` before MicThread construction. This is deliberately not described as a public stable Voice API. Its class is resolved only after an exact `2.6.24+26.2` version check; other existing Voice versions remain untouched and receive an honest unsupported-permission message.

The ordinary launcher preparation path selects the exact tested Modrinth version `Ls232EsW` from project `9eGKb6K1`, for managed Fabric26.2 profiles with active Votex Core. The shared dependency resolver verifies both exact project/version identity and compatibility before downloads; normal source/hash verification and transactional backups remain in effect. It does not drift to a future version whose internal API has not been tested. [Official project](https://modrinth.com/plugin/simple-voice-chat), [official version API](https://api.modrinth.com/v2/version/Ls232EsW).

The policy uses its own `config/votex/voice-setup.json` receipt. It does not change the existing performance/shader preparation key, Iris selection, game options, Sodium or Lithium preparation branches. Modpacks and profiles without active Core are excluded. Safe Mode already passes `prepare=false` and therefore never enters this path.

Existing enabled, disabled or renamed Voice Chat JARs remain intact. After one handled setup, removing Voice Chat does not reinstall it. A missing previously recorded Voice file, a pending remove/disable, or an applied addon transaction with a backed-up Voice JAR is treated as a user choice. The history inspection is bounded and refuses unsafe or malformed paths/receipts. Failure to download or validate the optional companion produces a clear launcher status without writing a success receipt or preventing ordinary Minecraft launch; the next launch may retry.

Native proof: `work/ingame-goal/run-04/evidence/voice-production-consent-proof.json`. A separate test-only last-resort callback vetoed the device even after the explicit permission action; microphone-thread and recorder objects stayed absent. This proves the permission lifecycle, not audible hardware playback.
