# Creator Collection - sources and licenses

The original Creator Collection contains nine third-party model adaptations. Another 65 specific Kenney CC0 adaptations are part of the in-progress free catalog (74 attributed adaptations in total). They are not represented as original Votex artwork. Original source files remain in assets-source/third-party/.

Each conversion changes scale, orientation, renderer format and player attachment. Angel/bat symmetry, hat fitting and studio materials are adapted. Original Quaternius animations are not included as Votex emotes. Source normal/mask maps are retained with the angel source but are not used by the Core renderer.

## Curated Kenney additions (in-game goal work)

The 65 exact model identities and official sources are documented in [CATALOG-COVERAGE.md](CATALOG-COVERAGE.md). Original GLBs, textures and CC0 license notices remain in `assets-source/third-party/kenney-curated/`; `manifest.json` records each archive-relative source identity and SHA256. Original geometry, author attribution and source licenses remain distinguishable from Votex-created assets.

The additions preserve their source geometry and palette textures, fitted as static shoulder companions, novelty headpieces or back accessories. NoRisk assets were not used, and original source animation clips are not presented as Votex emotes. Fitted projections have been reviewed; native runtime review remains pending. No 300+ catalog claim is made.
