# Profile defaults, class memory and native windows — 2026-10-23

This is ongoing source work, separate from the immutable 2026-10-22 EXE preview. It does not establish final acceptance of the full in-game goal.

## Requested behavior and implementation

- Newly created profiles and the first fresh launcher profile have opt-out Sodium, Iris Shaders, Mod Menu and Zoomify choices. Required dependencies follow the existing version/loader resolver and verified downloads. Removing Sodium from the selection also removes Iris and shader activation; enabling Iris selects Sodium.
- Performance/maximum-relief defaults select Lithium, FerriteCore and ImmediatelyFast in addition to the chosen basics. Cinematic offers Complementary Reimagined and BSL, individually selectable, and initially chooses one installed shader. Personal saved class settings override these defaults. All catalog files are downloaded from official sources at runtime; this does not bundle third-party mods/shaders into the preview.
- More Mods offers Xaero’s Minimap, Xaero’s World Map, AppleSkin, 3D Skin Layers, Simple Voice Chat and Mouse Tweaks. Each can be excluded. The More Mods group begins off in a fresh profile. For Core's Fabric26.2 internal Voice adapter, installation stays pinned to the previously native-tested SVC2.6.24+26.2 version; the current catalog also has2.6.25, which is not silently substituted for that adapter.
- Preparation runs after saving a new profile, including the copied-mods flow, and before ordinary launch. Imported modpacks retain their own policy. Existing profiles without the new selection retain the old policy. Per-target receipts preserve later user disable/removal choices; a download report under Performance records unavailable items and reasons. Optional missing versions do not abort the base launch. A universal, exhaustive download of every performance mod or shader on the platform is not implemented; these are named compatible starting selections.
- Native Votex workspaces can move by their title area and resize at four corners/all edges. Minimum dimensions retain readable type; smaller viewports reflow/scroll. Normalized geometry persists in modules.json and clamps to the new viewport. Later additions provide native cursor feedback and save an interrupted drag on close; those two small additions are compiled, not independently native-retested.
- First-person emotes render the actual selected skin's arms through the same pose rig, without forcing a camera switch or mutating held items. A separate cached classic/slim mesh freezes transforms into the submitted matrix before deferred rendering. Legs/full-body emotes naturally cannot all be seen from a forward-facing first-person camera; this is not a full-body first-person mod or forced camera animation.
- Saved class values now include GUI scale, FOV, FPS/unlimited, view/simulation distance, graphics/custom graphics, VSync, shader enable, RAM, optional performance-package selection, 22 visual option keys and Votex engine preferences. New profiles inherit the latest saved class bank. This does not copy keybindings, sound-device settings or arbitrary mod configuration between classes.
- The launcher imports saved options.txt, Iris enable state and performance.json on state load, changed-file detection during a launcher-owned game process, and game exit. A receipt prevents stale game files from overriding a newer unapplied launcher edit. Reverse sync leaves options.txt untouched. The frontend preserves unrelated pending theme changes during an external refresh. Unsaved settings still open in a Minecraft dialog are not filesystem changes and cannot be imported until Minecraft saves them.
