# Native two-player handshake contact

The previous fixed arm rotation could reach neither a close player nor the full permitted1.8-block range consistently. The new `HandshakeRig` targets one shared world midpoint and height. It keeps each arm's original length and bends the torso about its existing hip. A bounded search runs only when pair distance, height, player scale or classic/slim geometry changes. A canonical UUID order gives both recipients the same geometric solve.

The rendered right palm is the actual local arm point `(gripX,9,0)`, with classic/slim gripX values. The solver accounts for Minecraft's native0.9375 player scale,1.501 model origin, right shoulder pivot and native Euler order. Orientation and frozen contact angles belong to the extracted render state. It changes no entity position, hitbox, camera rotation or input. Sleeves/jacket/hat stay child layers rather than receiving duplicate parent transforms. Entry, release and interruption blend smoothly; physically unreachable stances cancel and ask the local participant to move closer or to similar ground height.

Pure tests cover classic/slim pairs, different adult scales, small height offsets, all tested headings, canonical participant swapping, fixed lengths and rejected invalid/unreachable input.
