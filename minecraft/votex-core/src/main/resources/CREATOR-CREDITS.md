# Creator Collection - sources and licenses

The free source catalog contains 278 attributed third-party adaptations: nine initial Creator Collection models, 65 specific Kenney CC0 adaptations and 204 additional individually licensed original models. Together with 36 Votex originals, the catalog has 314 entries, 311 excluding capes. These adaptations are not represented as original Votex artwork. Original source files remain in assets-source/third-party/.

Each conversion changes scale, orientation, renderer format and player attachment. Angel/bat symmetry, hat fitting and studio materials are adapted. Original Quaternius animations are not included as Votex emotes. Source normal/mask maps are retained with the angel source but are not used by the Core renderer.

## Curated Kenney additions (in-game goal work)

The 65 exact model identities and official sources are documented in [CATALOG-COVERAGE.md](CATALOG-COVERAGE.md). Original GLBs, textures and CC0 license notices remain in `assets-source/third-party/kenney-curated/`; `manifest.json` records each archive-relative source identity and SHA256. Original geometry, author attribution and source licenses remain distinguishable from Votex-created assets.

The additions preserve their source geometry and palette textures, fitted as static shoulder companions, novelty headpieces or back accessories. NoRisk assets were not used, and original source animation clips are not presented as Votex emotes. Fitted projections and all 314 actual native neutral attachment views were reviewed. Arbitrary outfit/animation/scale combinations are not exhaustively verified. These are active source changes, not a release announcement.

## Individually licensed additions

The 204 additional adaptations comprise 160 CC0 and 44 CC BY 3.0 models. Every original author, source model link, license link and adaptation notice is listed in [Poly-Catalog.md](licenses/Poly-Catalog.md). Original source GLBs, publisher records, source SHA256 and exact fitted model approvals remain under `assets-source/third-party/poly-curated/`. Source animation clips were not imported as Votex emotes. The original asset licenses remain in force.
